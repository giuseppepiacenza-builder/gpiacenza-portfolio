SmartStamp Web

SmartStamp is the integrity layer for physical artworks and collectibles, built for galleries, auction houses and other art businesses. The web platform keeps each piece's fingerprint, provenance record and documents in one place, on top of the tools a gallery already uses.

Overview

Most gallery software stops at inventory. SmartStamp also links each record to the physical object, whether an artwork or a collectible. Each piece is registered with microscopes mounted on gantries, which capture the surface texture of selected details as a digital fingerprint. The piece can then be verified with a mobile phone or with another microscope, by matching new captures against that fingerprint. The web platform holds everything around it: the ownership history, documents and signatures, and collection data imported from CSV files or the mobile app. I built the full frontend from scratch, with a service layer where every data dependency is injected through typed interfaces, so the UI stays independent of the backend.

Forged certificates
Paper certificates can be copied or forged. SmartStamp ties trust to the object itself, through a fingerprint of its surface.
Scattered provenance
Ownership history, exhibition records, appraisals and condition reports end up spread across emails and spreadsheets. SmartStamp keeps them in one record per artwork.
Manual document workflows
Contracts and certificates are drafted in Word and chased over email. SmartStamp generates and edits 13 document types and sends them for signature without a separate e-signature tool.
Disconnected collection data
Gallery data usually sits in separate systems or spreadsheets. SmartStamp imports it from CSV exports and the mobile app and adds verification on top.

Fingerprint registration and verification

Registration is carried out with microscopes mounted on gantries, which capture close-up images of selected surface details such as brushwork, gilding and engraving. Together these captures form the fingerprint of the piece. The fingerprint can then be cross-verified with another microscope or with a mobile phone, and each matched detail returns a score. Verified works carry the Integrity Stamp throughout the web app, in grids, tables and detail views. Unverified works show a muted outline badge.

Collection registry

The registry has two views: a masonry grid (24 items per page) and a data table (50 items). The active view, filters, and search query all live in the URL, so browser back and forward work as expected and you can share a filtered view as a link. Search runs across title, artist, and medium as you type. One click filters down to stamped or unstamped works only.

Provenance record

Each artwork has a provenance record built from five sections: the ownership history (acquisition method, price, verified status), exhibition appearances, publications, appraisals in any currency, and condition reports with photo attachments. Every time something is added, it gets written into the hash trail as a timestamped SHA-256 entry.

Document generation and signing

SmartStamp generates 13 artwork document types and 6 gallery-level ones from branded HTML templates. You can edit the content before locking it, then send it for signing via a link. The person signing doesn't need an account. Status goes from draft to pending to signed, and every signing event gets recorded in the hash trail.

Collection integrity dashboard

The dashboard shows fingerprint coverage as an animated progress bar, a breakdown of where artworks came from (CSV, mobile app, or manual entry), a summary of the documents vault, and a recent activity feed. The stat numbers count up on load using a custom easing curve.

Design system

The UI follows the look of a gallery viewing room: warm whites, near-black text, sharp edges (no border radius except on pills) and restrained colour. Orange is reserved for the brand. Verified works carry a near-black Integrity Stamp, and unverified works a muted grey outline. Every colour, shadow and spacing value is a CSS custom property, consumed through Tailwind utility classes.
